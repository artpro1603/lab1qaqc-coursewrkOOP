# Labwork21 — Airline Booking System

Навчальний проєкт з ООП (курсова робота), Spring Boot REST API для авіакомпанії.

## Що вміє
- CRUD для літаків, рейсів, пасажирів, класів місць та бронювань
- Пошук і аналітика по рейсах
- REST API з документацією через Swagger/OpenAPI
- Обробка помилок через глобальний exception handler

## Стек
Java, Spring Boot, Maven

## Запуск
```
mvn spring-boot:run
```
